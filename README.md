# Art by Blockchain

Art by Blockchain turns real Solana blockchain data into one-of-a-kind
generative artworks, drawn entirely out of math, and lets you mint them as
NFTs.

## What this is, in plain English

Every image here isn't drawn or painted, it's calculated. Each pixel's color
comes from a mathematical formula built out of nothing but cosines,
exponentials, absolute values and a handful of other simple functions. Feed
the same numbers in, and you get exactly the same picture out, every time, on
any computer.

Where do the numbers come from? A Solana block. Each artwork is seeded by
real, public blockchain data (a block hash and slot number) that gets turned
into the parameters of the formula. So every piece is tied to a specific,
verifiable moment on-chain, nobody, including us, chose how it looks, the
blockchain did.

There's also a "create" mode where you describe an image in words (or upload
a picture) and an AI model translates that description into a matching
formula, instead of using block data as the seed.

Once an image exists, it can be minted as an NFT, claiming that specific slot
as your own.

## Inspired by

- **Hamid Naderi Yeganeh**, a mathematician and artist known for building
  portraits, waves and figures purely out of trigonometric formulas like
  cosine and arccos. The core rendering technique here, clamp curves, step
  masks, layered shapes, comes directly from his approach to turning
  equations into recognizable images.
- The **on-chain generative art movement** (in the spirit of projects like
  Art Blocks), where the art is generated by code and the blockchain provides
  the source of randomness and provenance instead of a human picking pixels.

## What's done

- **The formula engine**: takes a set of parameters and renders them three
  ways, a fast JavaScript renderer (the canonical version used for minting),
  a GLSL/WebGL version for instant live preview in the browser, and a
  readable LaTeX version so you can see the actual math behind any image.
- **Solana block art**: pulls a real block from Solana and deterministically
  turns its data into an artwork.
- **Text/image to art**: describe or upload an image and an LLM converts it
  into formula parameters (or falls back to preset formulas if no AI key is
  configured).
- **A gallery** of recently generated slots, and a page listing past mints.
- **Deterministic rendering**: the same input always produces byte-for-byte
  the same image, verified by an automated test suite and recorded hashes.
- **Automated tests and CI**, running on every push.

## What's left

- **Real minting.** Right now, "minting" is a placeholder: it validates the
  request, records the claim in a database, and returns fake addresses. It
  does not yet create a real NFT on Solana. That part (using Metaplex Core)
  is designed for, but not built yet.
- **Mainnet stays off** until minting is real; everything currently runs on
  devnet.

## Layout

- `packages/engine`: the formula engine, a zod parameter schema, a compiler
  from parameters to a small expression IR, and the three render backends
  above.
- `apps/web`: the Next.js app, block art, gallery, create, mints, and the
  API routes behind them.
- `MAPPING.md`: the exact rules that turn block data into parameters.

## Running locally

```bash
pnpm install
docker run -d --name slotart-pg -e POSTGRES_USER=slotart -e POSTGRES_PASSWORD=slotart \
  -e POSTGRES_DB=slotart -p 5433:5432 postgres:16-alpine
cp apps/web/.env.example apps/web/.env
pnpm --filter web db:generate && pnpm --filter web db:push
pnpm dev
```

Set `OPENROUTER_API_KEY` in `apps/web/.env` for the create page, or
`LLM_MOCK=1` to use presets instead of a model. The block pages need only a
public Solana RPC; the database is needed for minting and the mints page.

This repo also ships a `commit-msg` hook (`.githooks/commit-msg`) that strips
any AI co-author trailers from commit messages. Git doesn't enable hooks from
a fresh clone automatically, so run this once after cloning:

```bash
git config core.hooksPath .githooks
```

## Tests

```bash
pnpm --filter @slotart/engine test   # unit tests, writes sample PNGs to packages/engine/test/out
pnpm --filter web test               # LLM helpers and the mint service (needs Postgres)
pnpm --filter web e2e                # Playwright, runs against a mock Solana RPC and the mock model
```

GitHub Actions runs all three on every push (`.github/workflows/ci.yml`).
